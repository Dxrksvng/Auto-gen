# คู่มือ: สร้างจดหมายจากไฟล์ Excel

> **ข้อควรรู้:** คู่มือนี้เขียนไว้สำหรับระบบที่ **ยังเป็นข้อเสนอ ยังไม่มีอยู่จริง** ภาพหน้าจอทุกภาพเป็น **ภาพตัวอย่างหน้าจอ (mockup)** ที่จำลองขึ้นเพื่อให้เห็นหน้าตา ชื่อปุ่มและชื่อสถานะในคู่มือนี้ตรงกับภาพตัวอย่าง ส่วนช่องทางติดต่อและชื่อผู้รับผิดชอบที่ยังไม่ทราบ เขียนไว้ว่า **[TO CONFIRM]**

## ระบบนี้ทำอะไร

คุณกรอกข้อมูลลูกค้าในไฟล์ Excel แล้วระบบจะสร้างจดหมาย PDF ให้ 1 ฉบับต่อลูกค้า 1 แถว โดยใช้แบบฟอร์มจดหมายที่ผ่านการอนุมัติแล้ว

**เหมือน Mail Merge ใน Word:** ไฟล์ Excel คือรายชื่อ แบบฟอร์มคือจดหมายต้นแบบ และระบบเติมข้อมูลแต่ละแถวลงในจดหมายให้ ที่ต่างจาก Mail Merge คือ ระบบตรวจข้อมูลให้ก่อนสร้างจดหมาย และต้องมีผู้อนุมัติกดอนุมัติก่อนจึงจะได้ไฟล์จดหมายไปใช้

### ขั้นที่ 1 เลือกประเภทจดหมาย

กดปุ่ม **เลือกประเภทนี้** ใต้ชื่อ "จดหมายขอเอกสารเพิ่มเติม"

![ภาพตัวอย่างหน้าจอ (mockup): เลือกประเภทจดหมาย](mockup/screens/s1_choose.png)

### ขั้นที่ 2 กรอกไฟล์ตัวอย่าง

กดปุ่ม **ดาวน์โหลดไฟล์ตัวอย่าง (Excel)** แล้วกรอกข้อมูลลูกค้า **1 คนต่อ 1 แถว** ห้ามแก้ ลบ หรือสลับ **แถวบนสุด** (แถวหัวคอลัมน์)

![ภาพตัวอย่างหน้าจอ (mockup): ไฟล์ตัวอย่างและหน้าตาในไฟล์ Excel](mockup/screens/s2_download_fill.png)

### ขั้นที่ 3 ส่งไฟล์ให้ระบบตรวจ

กดปุ่ม **เลือกไฟล์** เลือกไฟล์ที่กรอกแล้ว จากนั้นกดปุ่ม **ตรวจไฟล์**

![ภาพตัวอย่างหน้าจอ (mockup): เลือกไฟล์แล้วกดตรวจไฟล์](mockup/screens/s3_upload.png)

### ขั้นที่ 4 อ่านผลการตรวจ

ดูตัวเลข 3 ช่อง ได้แก่ **พร้อมสร้างจดหมาย**, **ต้องแก้ไข** และ **ไม่ต้องส่งจดหมาย** แล้วบวกกัน **ผลรวมต้องเท่ากับจำนวนแถวในไฟล์ของคุณ** ถ้าไม่เท่า อย่าทำต่อ ให้ดูหัวข้อ "ถามบ่อย"

![ภาพตัวอย่างหน้าจอ (mockup): ผลตรวจที่ไม่มีรายการต้องแก้ ผลรวม 3 + 0 + 2 เท่ากับ 5 แถว](mockup/screens/s4_result_ok.png)

ถ้าช่อง **ต้องแก้ไข** ไม่ใช่ 0 ให้กดปุ่ม **ดาวน์โหลดรายการที่ต้องแก้** แล้วทำตามหัวข้อ "ข้อความที่เห็นและวิธีแก้" ด้านล่าง

![ภาพตัวอย่างหน้าจอ (mockup): ผลตรวจที่มีรายการต้องแก้](mockup/screens/s4b_result_errors.png)

### ขั้นที่ 5 ตรวจตัวอย่างจดหมาย

ระบบแสดงตัวอย่างจดหมาย 3 ฉบับ ให้เปิดดูและตอบให้ได้ว่า "ใช่" ทุกข้อใน **เช็กลิสต์ก่อนส่งขออนุมัติ** (ดูหัวข้อ "เช็กลิสต์" ด้านล่าง)

![ภาพตัวอย่างหน้าจอ (mockup): ตัวอย่างจดหมายและเช็กลิสต์](mockup/screens/s5_preview.png)

## ข้อความที่เห็นและวิธีแก้

อ่านจากซ้ายไปขวา: **ข้อความที่เห็น → ความหมาย → วิธีแก้** ในรายการที่ดาวน์โหลดจะบอก **แถวที่** และ **ช่อง** ที่มีปัญหาให้ด้วย

### ข้อความเกี่ยวกับแต่ละแถว

| ข้อความที่เห็น | ความหมาย | วิธีแก้ |
|---|---|---|
| **ต้องแก้ไข**: ช่องนี้ว่างอยู่ | ช่องนี้ว่างอยู่ (ชื่อลูกค้า เลขกรมธรรม์ ชื่อโรงพยาบาล หรือสถานะ) | กรอกข้อมูลในช่องนั้นให้ครบ แล้วอัปโหลดไฟล์อีกครั้ง |
| **ต้องแก้ไข**: วันที่ไม่ถูกต้อง | ช่องวันที่ไม่ใช่วันที่ที่ Excel อ่านได้ เช่น พิมพ์เป็นตัวหนังสือ | คลิกเซลล์ เลือกรูปแบบเป็น "วันที่" แล้วพิมพ์วันที่ใหม่ |
| **ต้องแก้ไข**: วันสิ้นสุดมาก่อนวันเริ่ม | วันสิ้นสุดความคุ้มครองมาก่อนวันเริ่ม | ตรวจวันที่สองช่อง แล้วแก้ให้วันเริ่มมาก่อนวันสิ้นสุด |
| **ต้องแก้ไข**: สถานะไม่ตรงที่ระบบรู้จัก | สถานะไม่ตรงกับที่ระบบรู้จัก (REQUEST_DOC, APPROVED, REJECTED) | พิมพ์ให้ตรงตัวอักษรทุกตัว ถ้าเป็นสถานะใหม่ให้แจ้งเจ้าของงาน อย่าแก้เอง |
| **ต้องแก้ไข**: รายการเอกสารเขียนไม่ตรงรูปแบบ | ช่องรายการเอกสารเขียนไม่ตรงรูปแบบ | ใช้รูปแบบเดียวกับไฟล์ตัวอย่าง คือ ["เอกสาร 1","เอกสาร 2"] ครบทั้งวงเล็บและเครื่องหมายคำพูด |
| **ต้องแก้ไข**: ไม่มีรายการเอกสาร | สถานะเป็นขอเอกสาร (REQUEST_DOC) แต่ไม่มีรายการเอกสาร | ใส่รายการเอกสารอย่างน้อย 1 รายการ หรือถามเจ้าของงานว่าสถานะถูกหรือไม่ |
| **ไม่ต้องส่งจดหมาย**: ไม่ต้องส่งจดหมาย (สถานะ APPROVED) | สถานะ APPROVED ไม่ต้องขอเอกสารเพิ่ม (A2 บันทึกว่า status=APPROVED) | ไม่ต้องทำอะไร |
| **ไม่ต้องส่งจดหมาย**: ไม่ต้องส่งจดหมาย (สถานะ REJECTED) | สถานะ REJECTED ไม่ต้องขอเอกสารเพิ่ม (A2 บันทึกว่า status=REJECTED) | ไม่ต้องทำอะไร |
| **ต้องตรวจสอบ**: เหมือนกับที่เคยสร้างในรอบก่อน | แถวนี้เหมือนกับที่เคยสร้างไว้ในรอบก่อน | ถ้าไม่ตั้งใจให้ลบแถวออก ถ้าตั้งใจให้ระบุเหตุผลแล้วกดยืนยัน |
| **ต้องตรวจสอบ**: ชื่อเอกสารยังไม่อยู่ในรายการที่ตกลงกัน | ชื่อเอกสารนี้ยังไม่อยู่ในรายการชื่อที่ตกลงกันไว้ | แจ้งเจ้าของงานให้เพิ่มชื่อ อย่าแก้ชื่อเอง |

### ข้อความเกี่ยวกับทั้งไฟล์ (ระบบหยุดตรวจจนกว่าจะแก้)

| ข้อความที่เห็น | ความหมาย | วิธีแก้ |
|---|---|---|
| หัวคอลัมน์ไม่ตรงกับไฟล์ตัวอย่าง | หัวคอลัมน์แถวบนสุดไม่ตรงกับไฟล์ตัวอย่าง | ห้ามแก้ ลบ หรือสลับหัวคอลัมน์ ให้ดาวน์โหลดไฟล์ตัวอย่างใหม่ แล้วคัดลอกข้อมูลไปวาง |
| เปิดไฟล์ไม่ได้ | เปิดไฟล์ไม่ได้ | บันทึกเป็นไฟล์ Excel อีกครั้ง ถ้าอยู่ใน Google Sheets ให้เลือก ไฟล์ > ดาวน์โหลด > Microsoft Excel |
| ไม่พบแผ่นงานชื่อ Sheet1 | ไม่พบแผ่นงานชื่อ Sheet1 | ตั้งชื่อแผ่นงานแรกว่า Sheet1 แล้วอัปโหลดอีกครั้ง |
| ไฟล์ไม่มีข้อมูล | ไฟล์ไม่มีข้อมูล | ตรวจว่าเลือกไฟล์ถูกต้อง แล้วอัปโหลดอีกครั้ง |

### ข้อความตอนสร้างจดหมาย

| ข้อความที่เห็น | ความหมาย | วิธีแก้ |
|---|---|---|
| สร้างจดหมายแถวนี้ไม่สำเร็จ | สร้างจดหมายของแถวนั้นไม่สำเร็จ (A2 บันทึก failed พร้อมข้อความผิดพลาด) | อย่าส่งจดหมายชุดนี้ จดรหัสรอบงานกับแถวที่มีปัญหา แล้วแจ้งทีมดูแลระบบ |

## ถามบ่อย

**ไฟล์ของฉันอยู่ใน Google Sheets ทำอย่างไร**
เลือกเมนู **ไฟล์ > ดาวน์โหลด > Microsoft Excel** แล้วใช้ไฟล์ที่ได้ในขั้นที่ 3 ห้ามส่งลิงก์ Google Sheets

**ถ้าอัปโหลดไฟล์ซ้ำสองครั้งจะเป็นอย่างไร**
ระบบนับเป็น **รอบงานใหม่** ทุกครั้ง และเทียบกับรอบก่อน ถ้าแถวไหนเหมือนที่เคยสร้างแล้ว จะขึ้นสถานะ **ต้องตรวจสอบ** ให้ลบแถวนั้นออก หรือระบุเหตุผลแล้วกดยืนยัน ระบบจะไม่ปล่อยจดหมายซ้ำโดยไม่มีผู้อนุมัติ

**ใครเป็นผู้อนุมัติ**
[TO CONFIRM: ธุรกิจเป็นผู้กำหนด] ถ้าไม่แน่ใจ ถามหัวหน้าทีมของคุณก่อนกดส่งขออนุมัติ

**ผลรวมตัวเลขไม่เท่ากับจำนวนแถวในไฟล์ ทำอย่างไร**
อย่าทำต่อ ตรวจว่ามีแถวว่างกลางไฟล์หรือไม่ แล้วลองอัปโหลดใหม่ ถ้ายังไม่เท่า ให้แจ้งทีมดูแลระบบ พร้อมรหัสรอบงาน

**อยากแก้ข้อความในจดหมาย ทำได้ไหม**
แก้เองไม่ได้ ให้แจ้งเจ้าของแบบฟอร์ม [TO CONFIRM] การแก้แบบฟอร์มต้องผ่านการอนุมัติ และจะได้แบบฟอร์มฉบับใหม่ จดหมายที่สร้างไปแล้วจะไม่เปลี่ยน

**แก้ไฟล์ PDF เองได้ไหม**
ไม่ได้ ให้แก้ที่ไฟล์ Excel แล้วทำรอบงานใหม่

**ภาษาไทยในจดหมายผิดหรือตัวอักษรขาด**
อย่าส่ง แจ้งทีมดูแลระบบ พร้อมรหัสรอบงานและแถวที่ ปัญหานี้ต้องแก้ที่ระบบ แก้ในไฟล์ Excel ไม่ได้

**จะส่งไฟล์ที่มีข้อมูลลูกค้าให้เพื่อนร่วมงานทางอีเมลได้ไหม**
ใช้เฉพาะช่องทางที่บริษัทอนุญาต [TO CONFIRM] ข้อมูลลูกค้าเป็นข้อมูลส่วนบุคคลและมีข้อมูลสุขภาพ อย่าแนบในข้อความขอความช่วยเหลือ
